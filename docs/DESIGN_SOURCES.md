# EyeRest design sources

Checked on 21 November 2026. This document records guidance and observations used to evaluate EyeRest's app icon, iOS presentation, and static website. It does not copy layouts, text, images, or code from the reference products.

### Icon decision

The current icon uses one centered concept, no text or border, an approximately 80% eye width, strong 61 px strokes, and consistent default/dark/tinted geometry. Its generated assets are opaque 1024×1024 images, and prior visual inspection found the eye outline, iris ring, and hands distinguishable at 60 px and recognizable at 29 px. The sourced guidance identifies no concrete defect that justifies another icon change. The current raster asset-catalog format also remains compatible with the iOS 17 target and has passed the built-bundle icon assertions. Revisit only if physical-device testing exposes clipping, loss of detail, or appearance mismatch.

## Design principles adopted

1. State the outcome first and offer one primary action.
2. Keep factual limitations adjacent to the install action.
3. Use real app captures only when produced reliably; otherwise label the existing CSS device art “Illustration.”
4. Use an 8 px-based spacing rhythm with larger section gaps and restrained card density.
5. Keep prose widths readable, media dimensions explicit, and mobile layouts single-column without hidden information.
6. Treat privacy as verifiable behavior, not a mood or badge.
7. Make semantic HTML work without JavaScript; JavaScript may enhance the menu, theme, and copy controls.
8. Meet 4.5:1 text and 3:1 UI contrast in both themes, preserve visible focus, aim for 44 px targets, and respect reduced motion.
9. Preserve EyeRest's eye-clock, lime, deep-green, DM Sans, and Instrument Serif identity; do not restyle for novelty.
