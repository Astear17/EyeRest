Privacy

Your routine stays
on your iPhone.

This notice describes the EyeRest app and this project website. Last updated November 21, 2026.

The EyeRest app

EyeRest is an offline-first iPhone app. The app code makes no network requests and includes no accounts, advertising, analytics, tracking, or third-party runtime services.

What the app stores

EyeRest stores the following data locally on your device:

  • Reminder settings, including which reminders are enabled, intervals, optional custom messages, next planned dates, active days, quiet hours, pause state, Snooze choice, notification priority, appearance, and haptics preference.
  • Activity records for completed actions and guided breaks, including reminder kind, completion time, duration, source, and an activity identifier when applicable.
  • Daily activity totals used for streaks, weekly break time, charts, and history.

Settings are stored in app preferences. Activity history is stored in the app's Application Support area. iOS controls the app's sandbox and device backups.

Notifications

EyeRest asks for iOS notification permission only after you complete the welcome screen or request permission in Settings. iOS stores and delivers the local notification requests. You can deny permission or change it later in iPhone Settings. Time Sensitive delivery may be unavailable depending on the signing profile; EyeRest then uses normal notification delivery.

Exports and imports

EyeRest creates a backup only when you choose Export backup. The exported JSON contains app settings and activity history. Notification permission and pending alerts are not included. You choose where the exported file goes and which file to import. Keep backups private if they reveal your routine.

No app network collection

The EyeRest app does not send the stored data to the project owner or any server. It does not fetch website content, contact analytics services, or load remote fonts.

This website

This website uses no analytics, advertising, tracking pixels, or cookies. It stores one theme choice in your browser's localStorage so light or dark mode persists. Fonts and images are served from the same site, so viewing a page does not request Google Fonts.

The site is hosted through GitHub Pages. GitHub may receive and log ordinary web requests, such as IP address, browser details, requested URL, and time, under GitHub's privacy statement. Links to GitHub Releases, Issues, and third-party signing tools take you to those services and their own policies.

Contact

For privacy questions or corrections, open an issue in the EyeRest GitHub Issues tracker. Do not include sensitive personal information in a public issue.
