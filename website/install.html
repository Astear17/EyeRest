Install outside the App Store

Sign it yourself.
Keep control.

EyeRest is not on the App Store and will not be. Releases contain an unsigned IPA: a packaged app that cannot run on your iPhone until you sign it with a tool and profile you trust.

Before you begin

Unsigned means not ready to install.

The release file contains the built EyeRest app but no usable device signature or provisioning profile. Never install a file whose source or SHA-256 you cannot verify.

1. Download the release

Latest EyeRest release

Download EyeRest-unsigned.ipa and its matching .sha256 file from GitHub Releases.

Open latest release

2. Verify SHA-256

Calculate the IPA's SHA-256 locally and compare every character with the value in the downloaded .sha256 file.

macOS or Linux

shasum -a 256 EyeRest-unsigned.ipa

Windows PowerShell

Get-FileHash .\EyeRest-unsigned.ipa -Algorithm SHA256

If the values differ, stop and delete the IPA. Download it again from the release page.

3. Sign and install

Choose a tool you trust. Examples include Feather, KSign, Sideloadly, and AltStore. Each has different certificate, Apple ID, pairing, computer, and iOS requirements. Follow that tool's official documentation; EyeRest does not operate or endorse any of them.

4. Finish on iPhone

  1. If iOS asks, open Settings → Privacy & Security → Developer Mode, enable it, and follow the restart confirmation.
  2. Open EyeRest.
  3. Read the welcome screen, tap Get started, and allow notifications if you want reminders.
  4. Choose active days, quiet hours, and reminder intervals in Settings.

What to expect

  • Free Apple ID signatures expire after about seven days. Re-sign before or after expiry using the same tool and identity where possible.
  • A signing tool may rewrite EyeRest's bundle identifier. A changed identifier creates a separate install with separate local data, so use Export backup before reinstalling.
  • Time Sensitive delivery depends on the signing profile and iPhone settings. EyeRest falls back to normal notifications when the capability is unavailable.
  • iOS limits pending notifications. EyeRest keeps a finite queue, so open the app now and then to replenish it.

Troubleshooting

iOS says the app's integrity cannot be verified

The IPA is unsigned or the signature/profile is invalid, revoked, expired, or does not match the device. Re-check the signing tool's requirements and sign again. EyeRest cannot repair signing credentials.

The app installs as a second copy

Your signing tool likely changed the bundle identifier. Export from the old copy before removing it, then import into the new copy. Keep the same identifier on future updates when your tool allows it.

No reminders arrive

Check iPhone notification permission, Focus, notification summaries, and the app's active days and quiet hours. Open EyeRest to refresh its limited queue. Time Sensitive may be unavailable with your profile; normal alerts should still be scheduled.

The app stopped opening after several days

A free Apple ID signature commonly expires after about seven days. Re-sign and reinstall with the same bundle identifier to preserve local data when the tool supports an in-place update.
