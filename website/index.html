Questions

The practical
details.

Is EyeRest on the App Store?

No. EyeRest is distributed as an unsigned IPA outside the App Store and is not planned for App Store distribution. The IPA cannot run until you sign it.

What does signing involve?

Download the latest release, verify its SHA-256, then use a signing and installation tool you trust. Tool requirements differ, and some free Apple ID signatures expire after about seven days.

Will reminders always arrive?

iOS controls final delivery. Permissions, Focus, notification summaries, battery state, and signing-profile capabilities can affect alerts. EyeRest keeps a limited queue, so open it now and then.

Does EyeRest need the internet?

The app itself makes no network requests. GitHub and this project website are used only to distribute files and documentation outside the app.
